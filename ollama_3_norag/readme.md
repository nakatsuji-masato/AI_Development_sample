# 商品データ検索 (非RAG)

非RAGを使った商品データ検索AIのテストサンプル
ベクトルデータなどを使用せずにプロンプトのテキスト情報みで商品を検索するテストサンプル

大まかな流れ的には下記  
(テストサンプルではjson形式の2ファイルにしている)

```
質問内容と全商品のカテゴリリストから
該当するカテゴリの候補をAIに出力
        ↓
DBにある商品データから
カテゴリ候補に該当するの商品情報リストを抽出
        ↓
商品情報リスト、カテゴリ候補、質問内容を基に商品情報を最終的に選択してその結果を出力
```

プロンプトに数万件等の膨大な全商品データを入れるのは  
仮にオンラインAIを使っても入力トークンのコスト増大につながる為良くない

RAGを使う場合、別途ベクトルデータ用の保存場所(DBテーブルまたはファイルベース等)が必要になるのと  
Embedのデータ設定や抽出がかなりややこしいので、  
どうしてもそれを避けなければならない場合はこの方法は使える 

ただし問題点として必ず2回送信する羽目になるため返答までの時間はその分遅い

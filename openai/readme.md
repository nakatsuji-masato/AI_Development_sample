# OpenAI (オンラインAI開発サンプル)

OpenAIを使ったオンラインでのAI開発テストサンプル

# 使い方

## 1. .envファイルの用意

OpenAIは従量課金制  
送信で使用されたトークンに対してコストが発生する為  
直下に.envファイルを用意して OpenAIに各自ログイン後に作成したAPIキー(SecretKey)のみを置く

## 2. テストサンプル(バイナリexe)の実行

Windows端末上であればすでに``openai.exe``があるのでそれを普通に実行する  
コンソール画面にて下記が出たらOK

```
--- OpenAI Test Sample ----
LLM = gpt-6-luna

YOUR: 
```

下記のように質問をしたらAIから答えが出てくる  
同時に使用トークン数が表示される仕様

```
YOUR: 3+2はいくつになる？
AI: 5です。
-------------------------
Usage Token
Input  =  14
Output =  7
Total  =  21
-------------------------

YOUR:
```

# コストについて

OpenAIの場合は使用モデルと入力トークンと出力トークンそれぞれで単価が異なる

例えば最小モデル``gpt-6-luna``の場合

- 入力トークン ... $0.10/100万トークン
- 出力トークン ... $0.50/100万トークン

例えば送信1回あたりの平均の入力トークン数を50、出力トークン数を500と見積もった場合  
1回あたりのコストは 

```
(50 x $0.1 + 500 x $0.5) / 1,000,000
= $0.000255 / 回
```

これでコスト累計が約$1(=約160円)を超えるには  
月に約3,921回実施する必要があるという計算になる

これは使用モデルを変更すれば当然トークンあたりの単価は変わる  
Lunaは最小モデルなのでこれよりはむしろこれよりは高くなるので  
変更する場合は注意

# 補足

- APIキーの.enfファイルは.gitignoreで管理対象外なので各自で用意
- OpenAIはクレジット購入をしないとエラーになるので、購入($10くらい)してから実施する
- デフォルトでモデルは最小の gpt-6-lunaとしている。コードで変更は可能

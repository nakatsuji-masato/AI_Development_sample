# 商品データ検索 (RAG)

RAGを使った商品データ検索AIのテストサンプル

初回および商品データ更新時は下記を行う

```
商品データの登録
    ↓
Embeddingモデルを使って商品データのベクトル化
    ↓
ベクトルデータの保存
```

質問された時は下記を行う

```
質問文をベクトル化
    ↓
ベクトルデータベースから検索
質問の意味的に近い商品データを抽出
    ↓
上位数件分の関連する商品データを取得
    ↓
生成AIに質問と商品データを送信
    ↓
AIが回答を生成
```
